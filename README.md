## 설치 방법
1. 폰(또는 패드)의 크롬에서 위 **받기** 링크를 눌러요
2. 다운로드가 끝나면 파일을 열어 **설치**
3. 처음 한 번은 "출처를 알 수 없는 앱 설치" 를 허용해야 해요 (설정 → 보안)
- 안드로이드 7.0 이상
- 새 버전을 덮어 설치해도 **저장 데이터는 그대로** 남아요 (앱을 삭제하면 데이터도 지워져요)
